# Harnix

**Add AI agents to your product. Create them, run them, and keep control of them.**

Harnix is a multi-tenant SaaS platform where a business creates AI agents, grounds
them in its own knowledge, connects them to its tools, and embeds them in its own
app with one `<harnix-chat>` widget. Every organization's data is isolated, and
every run is durable and traceable from the prompt to the answer.

- **Agents and knowledge bases**: choose the model and system prompt, upload documents, and get answers with citations.
- **Connectors**: give agents tools through remote MCP servers, with OAuth sign-in handled for you.
- **Embeddable chat**: drop the widget into any page, or call the API from your backend.
- **Control plane**: runs, traces, conversations, usage, token budgets and rate limits per organization.
