# Harnix

**Create, manage and run AI agents on your own infrastructure.**

Harnix is a multi-tenant platform for building AI agents, connecting them to your
knowledge and tools, and embedding them in your product with a single
`<harnix-chat>` widget. Every organization's data stays isolated, and every run
is traceable from the prompt to the answer.

- **Agents and knowledge bases**: configure the model, the system prompt and the documents an agent can search.
- **Connectors**: give agents tools through MCP servers, with OAuth sign-in handled for you.
- **Embeddable chat**: drop the widget into any page, or call the API from your backend.
- **Control plane**: runs, traces, conversations, usage, token budgets and rate limits per organization.
